# Tamanly — Logo design

## Brand
**Tamanly** is a Malaysian neighborhood property management app (multi-tenant tamans, visitor QR, billing, facilities, marketplace).

## Logo system

### Mark (icon)
Gate-and-roofs community mark:
- **Structure:** Indigo house / taman gate with arched opening
- **Roofs:** Layered chevrons in coral and warm yellow (neighborhood density)
- **Accent:** Small warm-yellow sprout at lower left (growth / greenery)

Keep the mark unchanged across lockups; it is the primary recognition asset.

### Wordmark
Wordmark reads **Tamanly** (capital T, lowercase remainder), set to the right of the mark in horizontal lockups.

#### Font
| Use | Family | Weight | Notes |
|-----|--------|--------|-------|
| **Production wordmark** | **Inter** | Medium (500) | Polished, confident geometric sans; high legibility at small sizes |
| Alternate (warmer) | Plus Jakarta Sans | Medium (500) | Only if a slightly softer Malaysian-friendly tone is preferred |

**AI mockups:** Generated logo images use AI-drawn letterforms that *approximate* Inter Medium — they are not true font outlines. Always rebuild the wordmark in Inter for final assets (SVG/PDF).

**Tracking:** Slightly tight (−1% to −2%) for a refined proptech feel. Avoid rounded/playful display faces.

### Color palette
| Role | Color | Approx. hex |
|------|-------|-------------|
| Primary (mark body, wordmark) | Indigo | `#3D2B6B` |
| Accent | Coral | `#E87A6B` |
| Highlight | Warm yellow | `#E8B84A` |
| Ground | Warm cream / off-white | `#F7F3EC` |

Hex values are approximate from the current renders — lock exact tokens in the design system once brand guidelines are finalized.

### Style
Warm **Material Design**: soft elevation, rounded geometry, friendly but professional. Not playful; not cold corporate.

### File variants
| Asset | Purpose |
|-------|---------|
| App icon (1:1) | Avatar, app store, favicon |
| Horizontal lockup (mark + wordmark) | Headers, marketing, docs |
| Mark-only | Small UI, favicon fallback |

### Do / don’t
- **Do** keep indigo / coral / warm yellow ratios consistent
- **Do** set the live wordmark in **Inter Medium**
- **Don’t** replace Inter with rounded bubble fonts
- **Don’t** recolor the roofs arbitrarily or drop the sprout without a documented variant
