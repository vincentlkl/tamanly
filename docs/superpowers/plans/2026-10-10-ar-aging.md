# AR Aging, Credit Notes & Debit Notes — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **Also REQUIRED:** invoke the `ponytail:ponytail` skill (level **full**) before writing any code, and keep it on for every task. Shortest working diff, no unrequested abstractions, business logic in services.

**Goal:** Admins of one taman can see and export an Accounts Receivable aging report. It comes in two forms:
- a summary of every unit with a balance;
- a per-unit detail, also usable as a statement for the owner.

Both split the balance into Current / 1–30 / 31–60 / 61–90 / 91+ days past due. Credit notes and debit notes become first-class documents with line items, and partial payments are tracked properly.

**Architecture:**
- **Balances live on the documents.** Every document keeps its own balance counters: `paid_cents` and `credited_cents` on invoices and debit notes, `applied_cents` on payments and credit notes.
- **One writer.** Only the `Billing::Allocations` service writes those counters, through an `allocations` table. It locks both rows.
- **No cache for the report.** Buckets move every midnight without a write, so the aging report is computed live: two `GROUP BY` queries per taman. Nothing is cached.
- **PDFs run in the background.** They are Prawn PDFs rendered by a Solid Queue job, stored on a `report_exports` row and pushed to the page over Turbo Streams.
- **Numbering is configurable.** Document numbers for invoices, debit notes and credit notes use a pattern set per organization, counted per taman.

**Tech Stack:** Rails 8.1, Ruby 4.0, PostgreSQL, Hotwire (Turbo + Stimulus), Tailwind, Minitest, Solid Queue, Active Storage, Prawn + prawn-table (new), pdf-inspector (new, test only).

**Spec:** The decisions table below. It was agreed with the product owner on 2026-10-10. Read it before Task 0; every task argues from it.

## Decisions (the spec)

| # | Decision |
|---|---|
| D1 | **Credit notes and debit notes are their own documents** (own tables), each with **line items**, an amount and an outstanding amount. |
| D2 | **Lines:** one shared `billing_lines` table (polymorphic `document`), used by credit and debit notes only. Invoices keep their single amount. A note's amount = the sum of its lines. Lines can't be changed after issue: void the note and issue a new one. |
| D3 | **The report's row is the unit**, labelled with the current owner's name. |
| D4 | **Aging runs by `due_on`, as of today only.** No historical as-of date. |
| D5 | **Buckets:** **Current** = not yet due (days past due ≤ 0), then **1–30**, **31–60**, **61–90**, **91+** days past due. |
| D6 | **No unit-level counter caches.** The cached figure is each document's own balance. The report is one indexed `GROUP BY` with a `CASE` per bucket, backed by partial indexes on open documents (invoices and debit notes). |
| D7 | **Applying money:** an `allocations` table links a source (Payment or CreditNote) to a target (Invoice or DebitNote).<br>• `Billing::Allocations` is the only code that writes `paid_cents`, `credited_cents` and `applied_cents`.<br>• It locks rows in id order.<br>• Applying with no amount means as much as both sides allow, so a smaller payment **partially pays** the document and a larger one leaves the rest **unapplied**. |
| D8 | **Unapplied money** = unapplied payments (Matched or Unmatched, with a unit, kind Invoice) plus unapplied credit notes. It shows in an **Unapplied** column, and **Net** = Total − Unapplied. The buckets age the document balances only. |
| D9 | **Remove "Mark paid".** Every paid sen must trace back to a payment. "Record payment" covers the same need. |
| D10 | **Pre-launch: no data backfill.** Migrations add schema only; the seeds are rebuilt. |
| D11 | **Credit note rules:** reference `CN-…`; a reason is required; the target invoice or debit note is optional. With a target, the note is applied straight away up to the target's balance, and any remainder stays unapplied on the unit. It can be voided only while nothing is applied. Refunding credit is out of scope. |
| D12 | **Debit note rules:** reference `DN-…`; the source invoice is optional; `due_on` = issued_on + the taman's `payment_term_days`. It takes payments and credits, and can be voided only while nothing is allocated. Late fees stay as invoices, and the late-fee policy doesn't apply to debit notes. |
| D13 | **Payment terms:** `tamans.payment_term_days`, integer, default 30, range 0–120. It's edited in a "Payment terms" panel on the Late fees & reminders page. It drives debit note and late-fee invoice due dates. Documents already issued don't change. |
| D14 | **Pages for notes:**<br>• "Credit notes" and "Debit notes" tabs on the Invoices page.<br>• Each note has a show page (lines, applied money, Void, Apply).<br>• A "New credit/debit note" form: unit, optional target, lines, reason.<br>• "Issue credit note" / "Issue debit note" buttons on the invoice page.<br>• "Apply to oldest" for unapplied money on the AR detail page. |
| D15 | **Placement:** a new sidebar group **"Finance reports"** → **"AR aging"**. The summary is at `/admin/ar-aging` and the detail at `/admin/ar-aging/:unit_id`. Services live in `app/services/finance/`. |
| D16 | **Summary filters:**<br>• search (unit / owner / phone);<br>• Owner select (owners with a balance);<br>• Block select;<br>• Overdue select (Any / 31+ / 61+ / 91+);<br>• sort by Unit / Largest total / Most 91+. |
| D17 | **Export:** CSV (summary and detail) as a direct download. PDF through a background job: summary (A4 landscape); one unit's "Statement of outstanding balance" (A4 portrait, worded for the owner); "Statements for all units with a balance" (one unit per page). |
| D18 | **Access:**<br>• The report needs the **billing view** permission. Notes and settings saves need **billing edit**. Operators always pass.<br>• Rule: a `requires_permission` class macro on `Admin::BaseController`.<br>• The sidebar is not filtered (follow-up). |
| D19 | **Document numbering:**<br>• The **pattern is set per organization**. The **counter runs per taman**, giving each taman an unbroken sequence.<br>• Tokens: `{YYYY}` `{YY}` `{MM}` `{SEQ:n}` (n = 3–8) and `{TAMAN}`. Reset: `never` / `yearly` / `monthly`.<br>• Validation: exactly one `{SEQ:n}`; monthly needs `{MM}` and a year token; yearly needs a year token; at most 30 characters; only `A–Z 0–9 - / .`.<br>• A "next number" field can only move the counter forward. The settings page previews the next number.<br>• Defaults: `INV-{YY}{MM}-{SEQ:5}`, `DN-{YY}{MM}-{SEQ:5}`, `CN-{YY}{MM}-{SEQ:5}`, all monthly.<br>• Uniqueness is `(taman_id, reference)`. `AutoMatch` builds its regex from the pattern. |
| D20 | **One balance formula:** the `Receivable` concern holds `balance_sql`, the scopes, `amount_due_cents` and `status`. No raw `amount_cents - paid_cents` stays anywhere.<br>• Owner portfolios show AR aging's **Net** per unit.<br>• The statements export adds Debit note rows (+) and Credit note rows (−).<br>• Analytics collection rate = paid ÷ (billed − credited).<br>• The invoice page shows "Credited" and the money applied.<br>• Voiding is refused while any allocation exists.<br>• Late fees are charged on the balance after credits.<br>• Credit note status is calculated: Open / Partially applied / Applied / Void. |
| D21 | **Tenancy:** each report covers exactly one taman (`Current.taman_ids`, which `Admin::BaseController` pins to a single taman). Nothing crosses tamans. |

## Review Focus

These five failure modes are implied by the spec but easy to miss. Each one has a pinned test in the task that owns the code.

1. **Double-applying the same money.** This happens when two staff click "Apply"/"Match" at once, or one person double-clicks. Counters must never pass the amount, and the second request should get "Nothing left to apply". Pinned in Task 3 (over-apply refused) and Task 1 (the DB check constraint refuses an overflow).
2. **Another taman's id or form token.** A unit id, document token or export id from another taman must 404 and never show. Pinned in Task 3 (`OpenDocuments.locate` on another taman's token) and Task 7 (foreign unit → 404).
3. **Owner name in a non-Latin script** (for example Chinese) in a PDF. The job must not crash; the name prints with `?`. Pinned in Task 10.
4. **Numbering changed mid-period.** If the reset or pattern is switched, or someone tries to lower the next number, the system must never hand out a duplicate reference. Pinned in Task 2 (taken number skipped; lowering refused).
5. **Units with only credit, and fully settled units.** A unit with only unapplied money must be listed with a negative Net; a fully settled unit must not be listed. Pinned in Task 5.

```ruby
# Invoices and debit notes: money a unit owes (AR aging plan). paid_cents and
# credited_cents are counters written only by Billing::Allocations. Status is
# computed, never stored (contracts.md §6).
module Receivable
  extend ActiveSupport::Concern

  included do
    has_many :allocations, as: :target, dependent: :restrict_with_exception

    scope :not_void, -> { where(voided_at: nil) }
    scope :open, -> { not_void.where("#{balance_sql} > 0") }
    scope :paid, -> { not_void.where("#{balance_sql} <= 0") }
    scope :overdue, -> { open.where("#{table_name}.due_on < ?", Date.current) }
    scope :partially_paid, -> { open.where("#{table_name}.paid_cents + #{table_name}.credited_cents > 0") }
    scope :due, -> { open.where(paid_cents: 0, credited_cents: 0).where("#{table_name}.due_on >= ?", Date.current) }
  end

  class_methods do
    # The one balance formula. Use it in every SUM / WHERE on balances.
    def balance_sql = "(#{table_name}.amount_cents - #{table_name}.paid_cents - #{table_name}.credited_cents)"
  end

  def amount_due_cents = amount_cents - paid_cents - credited_cents

  def status
    return "Void" if voided_at
    return "Paid" unless amount_due_cents.positive?
    return "Overdue" if due_on < Date.current

    (paid_cents + credited_cents).positive? ? "Partially paid" : "Due"
  end

  def overdue? = status == "Overdue"
end
```

```ruby
# Document numbering per organization (AR aging plan, D19). Counters live in
# reference_counters, one per taman and period; see Billing::DocumentNumber.
class NumberingFormat < ApplicationRecord
  belongs_to :organization

  KINDS = %w[invoice debit_note credit_note].freeze
  RESETS = %w[never yearly monthly].freeze
  DEFAULTS = {
    "invoice" => "INV-{YY}{MM}-{SEQ:5}",
    "debit_note" => "DN-{YY}{MM}-{SEQ:5}",
    "credit_note" => "CN-{YY}{MM}-{SEQ:5}"
  }.freeze
  TOKEN = /\{(YYYY|YY|MM|TAMAN|SEQ:([3-8]))\}/
  ALLOWED = %r{\A(?:[A-Z0-9\-/.]|\{(?:YYYY|YY|MM|TAMAN|SEQ:[3-8])\})+\z}

  validates :kind, inclusion: { in: KINDS }, uniqueness: { scope: :organization_id }
  validates :reset, inclusion: { in: RESETS }
  validates :pattern, format: { with: ALLOWED, message: "may only use A–Z, 0–9, - / . and the tokens shown" },
                      uniqueness: { scope: :organization_id, message: "is already used by another document type" }
  validate :pattern_rules

  # The saved format, or an unsaved default.
  def self.for(organization, kind)
    find_or_initialize_by(organization: organization, kind: kind.to_s) do |format|
      format.pattern = DEFAULTS.fetch(kind.to_s)
      format.reset = "monthly"
    end
  end

  private

  def pattern_rules
    text = pattern.to_s
    errors.add(:pattern, "needs exactly one {SEQ:n} counter") unless text.scan(/\{SEQ:\d\}/).size == 1
    year = text.match?(/\{YY(YY)?\}/)
    if reset == "monthly" && !(year && text.include?("{MM}"))
      errors.add(:pattern, "needs {MM} and {YY} or {YYYY} when the counter restarts every month")
    end
    errors.add(:pattern, "needs {YY} or {YYYY} when the counter restarts every year") if reset == "yearly" && !year
    sample = text.gsub(TOKEN) { $1 == "TAMAN" ? "X" * 10 : ($2 ? "9" * $2.to_i : $1) }
    errors.add(:pattern, "makes numbers longer than 30 characters") if sample.length > 30
  end
end
```

```ruby
# AR aging plan (D19): invoice / debit note / credit note numbers from the
# organization's NumberingFormat, counted per taman and period under a row lock.
module Billing
  module DocumentNumber
    module_function

    def next!(kind, taman:, on: Date.current)
      raise ArgumentError, "#{kind} numbers are counted per taman; pass the taman." unless taman.is_a?(Taman)

      format = NumberingFormat.for(taman.organization, kind)
      model = kind.to_s.camelize.constantize
      counter = counter_for(format, taman, on)
      counter.with_lock do
        loop do
          counter.increment!(:value)
          number = render(format, taman:, seq: counter.value, on:)
          # A number can already exist after the pattern or reset changed: skip it, never reuse it.
          break number unless model.unscoped.exists?(taman_id: taman.id, reference: number)
        end
      end
    end

    # The number next! would hand out, without using it.
    def preview(kind, taman:, on: Date.current)
      format = NumberingFormat.for(taman.organization, kind)
      used = ReferenceCounter.find_by(scope: taman.id, kind: format.kind, period: period(format, on))&.value || 0
      render(format, taman:, seq: used + 1, on:)
    end

    # "Next number" on the settings page: moves the counter forward only.
    def set_next!(kind, taman:, next_number:, on: Date.current)
      format = NumberingFormat.for(taman.organization, kind)
      counter = counter_for(format, taman, on)
      counter.with_lock do
        if next_number.to_i <= counter.value
          raise ArgumentError, "The next #{kind.to_s.humanize.downcase} number can't go below #{counter.value + 1}."
        end

        counter.update!(value: next_number.to_i - 1)
      end
    end

    def render(format, taman:, seq:, on:)
      format.pattern.gsub(NumberingFormat::TOKEN) do
        case $1
        when "YYYY" then on.strftime("%Y")
        when "YY" then on.strftime("%y")
        when "MM" then on.strftime("%m")
        when "TAMAN" then taman_code(taman)
        else seq.to_s.rjust($2.to_i, "0")
        end
      end
    end

    # Finds this format's numbers inside free text (payment references, hints).
    def regex(format, taman)
      Regexp.new(format.pattern.split(/(\{[^}]+\})/).map { |part|
        case part
        when "{YYYY}" then "\\d{4}"
        when "{YY}", "{MM}" then "\\d{2}"
        when "{TAMAN}" then Regexp.escape(taman_code(taman))
        when /\A\{SEQ:(\d)\}\z/ then "\\d{#{$1},}"
        else Regexp.escape(part)
        end
      }.join)
    end

    def period(format, on) = { "monthly" => on.strftime("%Y-%m"), "yearly" => on.strftime("%Y") }.fetch(format.reset, "-")

    def counter_for(format, taman, on)
      ReferenceCounter.lock.find_or_create_by!(scope: taman.id, kind: format.kind, period: period(format, on)) { it.value = 0 }
    end

    def taman_code(taman) = (taman.short_name.presence || taman.name).upcase.gsub(/[^A-Z0-9]/, "")[0, 10]
  end
end
```

```ruby
# turn a form value or a payment's text into one of them.
module Billing
  module OpenDocuments
    module_function

    def for_unit(unit_id)
      (Invoice.open.where(unit_id:) + DebitNote.open.where(unit_id:)).sort_by { [it.due_on, it.issued_on, it.reference] }
    end

    def token(document) = document.to_sgid(for: :billing_target).to_s

    def locate(token)
      document = GlobalID::Locator.locate_signed(token.to_s, for: :billing_target, only: [Invoice, DebitNote])
      raise ActiveRecord::RecordNotFound unless document && Array(Current.taman_ids).include?(document.taman_id)

      document
    end

    # The open invoice or debit note of this taman named in a payment reference or hint.
    def find_in_text(taman, text)
      return if text.blank?

          document = kind.camelize.constantize.open.find_by(taman_id: taman.id, reference:)
```

```ruby
# AR aging plan (D7): the only code that moves money between documents.
# Payments and credit notes (sources) settle invoices and debit notes (targets).
# Both counters change in the same transaction as the allocation row, under row
# locks taken in id order, so two staff applying at once can't double-apply or deadlock.
module Billing
  module Allocations
    SOURCES = %w[Payment CreditNote].freeze
    TARGETS = %w[Invoice DebitNote].freeze

    module_function

    # amount_cents nil = as much as both sides allow: a partial payment stays
    # partial, an overpayment leaves the rest unapplied on the source.
    def apply!(source:, target:, amount_cents: nil)
      check!(source, target)
      allocation = ApplicationRecord.transaction do
        lock_both(source, target)
        room = [source.unapplied_cents, target.amount_due_cents].min
        raise ArgumentError, "Nothing left to apply between #{source.reference} and #{target.reference}." unless room.positive?

        amount = amount_cents.nil? ? room : amount_cents.to_i
        raise ArgumentError, "Apply between RM 0.01 and #{Money.format(room)}." unless amount.between?(1, room)

        source.update!(applied_cents: source.applied_cents + amount)
        target.update!(column(source) => target[column(source)] + amount)
        Allocation.create!(taman_id: target.taman_id, source:, target:, amount_cents: amount, created_by: Current.user)
      end
      AuditEvent.record!(action: "allocation.applied", target: target,
                         metadata: { from: source.reference, amount_cents: allocation.amount_cents })
      allocation
    end

    def remove!(allocation)
      source = allocation.source
      target = allocation.target
      ApplicationRecord.transaction do
        lock_both(source, target)
        source.update!(applied_cents: source.applied_cents - allocation.amount_cents)
        target.update!(column(source) => target[column(source)] - allocation.amount_cents)
        allocation.destroy!
      end
      AuditEvent.record!(action: "allocation.removed", target: target,
                         metadata: { from: source.reference, amount_cents: allocation.amount_cents })
      allocation
    end

    # Applies what is left on a payment or credit note to the unit's oldest open documents.
    def apply_oldest_first!(source)
      applied = []
      OpenDocuments.for_unit(source.unit_id).each do |target|
        break unless source.unapplied_cents.positive?

        applied << apply!(source:, target:) # apply! reloads source under its lock
      end
      applied
    end

    def check!(source, target)
      raise ArgumentError, "Only payments and credit notes can be applied." unless SOURCES.include?(source.class.name)
      raise ArgumentError, "Money can only be applied to invoices and debit notes." unless TARGETS.include?(target.class.name)
      unless source.unit_id == target.unit_id && source.taman_id == target.taman_id
        raise ArgumentError, "#{source.reference} and #{target.reference} are for different units."
      end
      raise ArgumentError, "#{target.reference} is void." if target.voided_at
      raise ArgumentError, "#{source.reference} is void." if source.try(:voided_at)
    end

    def lock_both(first, second) = [first, second].sort_by(&:id).each(&:lock!)

    def column(source) = source.is_a?(Payment) ? :paid_cents : :credited_cents
  end
end
```

```ruby
# AR aging plan: what each unit of a taman owes, by days past the due date.
# Balances are the documents' own counters (Receivable), so a report is one
# GROUP BY per document type plus one per kind of unapplied money. Nothing is
# cached: buckets move every midnight without a write.
module Finance
  module ArAging
    Bucket = Data.define(:key, :label, :max_days, :tone) # max_days nil = no upper limit
    BUCKETS = [
      Bucket.new("current", "Current", 0, "ok"),
      Bucket.new("d1_30", "1–30 days", 30, "sun"),
      Bucket.new("d31_60", "31–60 days", 60, "coral"),
      Bucket.new("d61_90", "61–90 days", 90, "bad"),
      Bucket.new("d91", "91+ days", nil, "bad")
    ].freeze
    # The "Overdue" filter: at least this many days past due.
    MIN_DAYS = { "31" => %w[d31_60 d61_90 d91], "61" => %w[d61_90 d91], "91" => %w[d91] }.freeze

    Row = Data.define(:unit_id, :unit_name, :block_id, :block_name, :owner_id, :owner_name, :owner_phone,
                      :buckets, :total_cents, :unapplied_cents, :net_cents) do
      def past_due? = buckets.except("current").values.any?(&:positive?)
    end
    Totals = Data.define(:buckets, :total_cents, :unapplied_cents, :net_cents)
    Report = Data.define(:rows, :totals, :owners, :as_of)
    Line = Data.define(:document, :days_past_due, :bucket)
    Credit = Data.define(:document, :date, :unapplied_cents)
    Detail = Data.define(:unit, :row, :lines, :credits, :as_of)

    module_function

    # Summary page: filtered rows, their totals, and the owner filter options.
    def report(taman:, filters: {}, as_of: Date.current)
      all = rows(taman_ids: [taman.id], as_of:)
      shown = filter(all, filters)
      owners = all.filter_map { [it.owner_id, it.owner_name] if it.owner_id }.uniq.sort_by { it.last.to_s }
      Report.new(rows: shown, totals: totals(shown), owners:, as_of:)
    end

    # One unit: each open document with its bucket, plus unapplied payments and credit notes.
    def detail(unit:, as_of: Date.current)
      lines = Billing::OpenDocuments.for_unit(unit.id).map do |document|
        days = (as_of - document.due_on).to_i
        Line.new(document:, days_past_due: days, bucket: bucket_for(days))
      end
      credits = Payment.unapplied.where(unit_id: unit.id).order(:paid_at)
                       .map { Credit.new(document: it, date: it.paid_at&.to_date, unapplied_cents: it.unapplied_cents) } +
                CreditNote.unapplied.where(unit_id: unit.id).order(:issued_on)
                          .map { Credit.new(document: it, date: it.issued_on, unapplied_cents: it.unapplied_cents) }
      row = rows(taman_ids: [unit.taman_id], as_of:, unit_ids: [unit.id]).first || blank_row(unit)
      Detail.new(unit:, row:, lines:, credits:, as_of:)
    end

    # One Row per unit with an open balance or unapplied money, sorted by unit name.
    def rows(taman_ids:, as_of: Date.current, unit_ids: nil)
      owed = {}
      [Invoice, DebitNote].each do |model|
        scope = model.open.where(taman_id: taman_ids)
        scope = scope.where(unit_id: unit_ids) if unit_ids
        scope.group(:unit_id, Arel.sql(bucket_sql(model, as_of))).sum(Arel.sql(model.balance_sql))
             .each { |(unit_id, key), cents| (owed[unit_id] ||= zero_buckets)[key] += cents.to_i }
      end
      unapplied = Hash.new(0)
      [Payment.unapplied, CreditNote.unapplied].each do |scope|
        scope = scope.where(taman_id: taman_ids)
        scope = scope.where(unit_id: unit_ids) if unit_ids
        table = scope.klass.table_name
        scope.group(:unit_id).sum(Arel.sql("#{table}.amount_cents - #{table}.applied_cents"))
             .each { |unit_id, cents| unapplied[unit_id] += cents.to_i }
      end
      build_rows(owed, unapplied)
    end

    def build_rows(owed, unapplied)
      ids = owed.keys | unapplied.keys
      units = Unit.where(id: ids).includes(:block).index_by(&:id)
      # Earliest owner wins. index_by would keep whichever row Postgres returned last,
      # which disagrees with Unit#owner (find_by, first row) when a unit has two.
      owners = Occupancy.where(unit_id: ids, relationship: "owner", status: "Active").includes(:user)
                        .order(:started_on, :created_at)
                        .each_with_object({}) { |o, h| h[o.unit_id] ||= o }
      ids.filter_map do |id|
        unit = units[id] or next
        buckets = owed[id] || zero_buckets
        total = buckets.values.sum
        row_for(unit, owners[id], buckets:, total:, unapplied: unapplied[id])
      end.sort_by(&:unit_name)
    end

    def row_for(unit, owner, buckets:, total:, unapplied:)
      Row.new(unit_id: unit.id, unit_name: unit.name, block_id: unit.block_id, block_name: unit.block&.name,
              owner_id: owner&.user_id, owner_name: owner&.person_name, owner_phone: owner&.person_phone,
              buckets:, total_cents: total, unapplied_cents: unapplied, net_cents: total - unapplied)
    end

    def blank_row(unit)
      owner = unit.occupancies.where(relationship: "owner", status: "Active").order(:started_on, :created_at).first
      row_for(unit, owner, buckets: zero_buckets, total: 0, unapplied: 0)
    end

    def bucket_for(days) = BUCKETS.find { it.max_days.nil? || days <= it.max_days }

    # CASE expression naming each document's bucket from its due date, built from BUCKETS.
    def bucket_sql(model, as_of)
      days = ActiveRecord::Base.sanitize_sql_array(["(CAST(? AS date) - #{model.table_name}.due_on)", as_of])
      whens = BUCKETS.filter_map { "WHEN #{days} <= #{it.max_days} THEN '#{it.key}'" if it.max_days }
      "CASE #{whens.join(' ')} ELSE '#{BUCKETS.last.key}' END"
    end

    # ponytail: filters run in Ruby over one taman's rows (hundreds). Push into SQL if a taman passes ~5,000 units.
    def filter(rows, filters)
      f = filters.to_h.with_indifferent_access
      rows = rows.select { it.owner_id == f[:owner_id] } if f[:owner_id].present?
      rows = rows.select { it.block_id == f[:block_id] } if f[:block_id].present?
      if (keys = MIN_DAYS[f[:min_days].to_s])
        rows = rows.select { |row| keys.any? { row.buckets[it].positive? } }
      end
      if f[:q].present?
        q = f[:q].strip.downcase
        rows = rows.select { "#{it.unit_name} #{it.owner_name} #{it.owner_phone}".downcase.include?(q) }
      end
      case f[:sort]
      when "total" then rows.sort_by { -it.total_cents }
      when "d91" then rows.sort_by { -it.buckets["d91"] }
      else rows
      end
    end

    def totals(rows)
      Totals.new(buckets: BUCKETS.to_h { |b| [b.key, rows.sum { it.buckets[b.key] }] },
                 total_cents: rows.sum(&:total_cents), unapplied_cents: rows.sum(&:unapplied_cents),
                 net_cents: rows.sum(&:net_cents))
    end

    def zero_buckets = BUCKETS.to_h { [it.key, 0] }
  end
end
```

```ruby
  # AR aging plan: summary (index), one unit (show), CSV, PDF export and download.
  class ArAgingController < BaseController
    page "ar-aging"
    requires_permission "billing", :view

    def index
      @report = Finance::ArAging.report(taman: scope_taman, filters: filter_params)
      if params[:format] == "csv"
        return send_data Finance::ArAgingCsv.summary(@report), filename: "ar-aging-#{Date.current}.csv"
      end

      @pagy, @rows = pagy_array(@report.rows, items: 50)
      @blocks = Block.where(taman_id: scope_taman.id).order(:name)
      @exports = recent_exports
    end

    def show
      @detail = Finance::ArAging.detail(unit: Unit.in_scope.find(params[:id]))
      if params[:format] == "csv"
        return send_data Finance::ArAgingCsv.detail(@detail),
                         filename: "ar-aging-#{@detail.unit.name.parameterize}-#{Date.current}.csv"
      end

      @exports = recent_exports
    end

    def export
      kind = params[:kind].presence_in(ReportExport::KINDS) or return head(:bad_request)
      unit = Unit.in_scope.find(params[:unit_id]) if kind == "ar_aging_unit"
      Finance::ExportReport.request!(kind:, taman: scope_taman, filters: filter_params.merge(unit_id: unit&.id).compact)
      redirect_back fallback_location: admin_ar_aging_index_path,
                    notice: "Preparing the PDF. It appears under Exports when it is ready."
    end

    def download
      export = ReportExport.in_scope.ready.find(params[:export_id])
      send_data export.file.download, filename: export.file.filename.to_s, type: "application/pdf", disposition: "attachment"
    end

    private

    def filter_params = params.permit(:q, :owner_id, :block_id, :min_days, :sort).to_h

    def recent_exports = ReportExport.in_scope.includes(:requested_by).order(created_at: :desc).limit(10)
  end
end
```

```ruby
module Admin
  # Credit notes and debit notes share one controller; the route sets params[:kind] (AR aging plan D14).
  class NotesController < BaseController
    page "invoices"
    requires_permission "billing", :view, only: :show
    requires_permission "billing", :edit, only: [:new, :create, :transition]

    def show
      @note = model.in_scope.find(params[:id])
    end

    def new
      load_form
    end

    def create
      load_form
      raise ActiveRecord::RecordNotFound unless @unit

      note = if credit?
               Billing::IssueCreditNote.call(unit: @unit, lines: lines_param, reason: params[:reason], target: @against)
             else
               Billing::IssueDebitNote.call(unit: @unit, lines: lines_param, reason: params[:reason],
                                            source_invoice: (@against if @against.is_a?(Invoice)))
             end
      redirect_to [:admin, note], notice: "#{note.reference} issued."
    rescue ArgumentError, ActiveRecord::RecordInvalid => e
      @lines = lines_param
      @reason = params[:reason]
      flash.now[:alert] = e.message
      render :new, status: :unprocessable_entity
    end

    # void / apply / unapply / record_payment
    def transition
      @note = model.in_scope.find(params[:id])
      case params[:event]
      when "void"
        Billing::VoidDocument.call(@note, reason: params[:reason])
        flash[:notice] = "#{@note.reference} voided."
      when "apply"
        count = Billing::Allocations.apply_oldest_first!(@note).size
        flash[:notice] = "Applied to #{count} document#{'s' unless count == 1}."
      when "unapply"
        Billing::Allocations.remove!(@note.allocations.find(params[:allocation_id]))
        flash[:notice] = "Unapplied."
      when "record_payment"
        Payments::RecordManual.call(target: @note, amount_cents: Money.parse(params[:amount]),
                                    method: params[:method], reference: params[:ref])
        flash[:notice] = "Payment recorded against #{@note.reference}."
      end
      redirect_back fallback_location: [:admin, @note]
    rescue ArgumentError => e
      redirect_back fallback_location: [:admin, @note], alert: e.message
    end

    private

    def credit? = params[:kind] == "credit_note"

    def model = credit? ? CreditNote : DebitNote

    def lines_param = Array(params[:lines]).map { it.permit(:description, :amount).to_h }

    def load_form
      @against = Billing::OpenDocuments.locate(params[:against]) if params[:against].present?
      @unit = @against&.unit || (Unit.in_scope.find(params[:unit_id]) if params[:unit_id].present?)
      @units = Unit.in_scope.order(:name) unless @unit
      @targets = @unit ? Billing::OpenDocuments.for_unit(@unit.id) : []
    end
  end
end
```

```js
import { Controller } from "@hotwired/stimulus"

// Repeating form rows (note lines): add clones the last row blank; remove keeps at least one.
export default class extends Controller {
  static targets = ["list"]
  static values = { keep: String }

  add() {
    const last = this.listTarget.lastElementChild
    if (!last) return
    const row = last.cloneNode(true)
    row.querySelectorAll("input").forEach(input => { input.value = "" })
    this.listTarget.appendChild(row)
    row.querySelector("input")?.focus()
  }

  remove(event) {
    if (this.listTarget.children.length <= 1) {
      window.Tamanly?.toast?.(this.keepValue)
      return
    }
    event.target.closest("li").remove()
  }
}
```

```ruby
module Billing
  class SaveBillingSettings
    class << self
      def call(taman:, payment_term_days:, numbering:)
        formats = NumberingFormat::KINDS.map do |kind|
          attrs = numbering.to_h.fetch(kind, {})
          NumberingFormat.for(taman.organization, kind).tap do |format|
            format.pattern = attrs["pattern"].to_s.strip.upcase if attrs["pattern"].present?
            format.reset = attrs["reset"] if attrs["reset"].present?
          end
        end
        ApplicationRecord.transaction do
          taman.update!(payment_term_days: payment_term_days.to_i)
          formats.each(&:save!)
          NumberingFormat::KINDS.each do |kind|
            next_number = numbering.to_h.dig(kind, "next_number")
            DocumentNumber.set_next!(kind, taman:, next_number:) if next_number.present?
          end
        end
        AuditEvent.record!(action: "billing.settings_updated", target: taman,
                           metadata: { payment_term_days: taman.payment_term_days,
                                       numbering: formats.to_h { [it.kind, "#{it.pattern} (#{it.reset})"] } })
        formats
      end
    end
  end
```

```ruby
require "prawn/table"

# Shared Prawn layout for finance PDFs (AR aging plan D17): letterhead, tables,
# bucket strip, footer page numbers.
# ponytail: built-in Helvetica only draws Windows-1252, so other scripts (e.g.
# Chinese names) print as "?". Bundle a Noto Sans TTF with a CJK fallback when owners need them.
module PdfKit
  INK = "1E2235"
  MUTED = "6B7085"
  LINE = "E3E5EC"
  SHADE = "F4F5F8"
  MARGIN = [40, 36, 44, 36].freeze

  def letterhead(pdf, taman, title, subtitle)
    pdf.fill_color INK
    pdf.text safe(taman.name), size: 16, style: :bold
    contact = [taman.address, taman.phone, taman.email].compact_blank.join("  ·  ")
    pdf.text(safe(contact), size: 8.5, color: MUTED) if contact.present?
    pdf.move_down 8
    pdf.stroke_color LINE
    pdf.stroke_horizontal_rule
    pdf.move_down 12
    pdf.text safe(title), size: 13, style: :bold
    pdf.text safe(subtitle), size: 9, color: MUTED
    pdf.move_down 12
  end

  # rows: arrays of strings. num_cols: right-aligned column indexes. total: bold last row.
  def grid(pdf, header, rows, num_cols: [], total: false)
    data = [header, *rows].map { |row| row.map { safe(it) } }
    pdf.table(data, header: true, width: pdf.bounds.width,
                    cell_style: { size: 8, padding: [4, 5], border_color: LINE, border_width: 0.5, text_color: INK }) do |t|
      t.row(0).font_style = :bold
      t.row(0).background_color = SHADE
      num_cols.each { t.column(it).align = :right }
      if total
        t.row(-1).font_style = :bold
        t.row(-1).background_color = SHADE
      end
    end
  end

  # [[label, cents], …] as one shaded strip of totals.
  def strip(pdf, pairs)
    pdf.table([pairs.map { |label, cents| safe("#{label}\n#{money(cents)}") }], width: pdf.bounds.width,
              cell_style: { size: 9, padding: 7, align: :center, border_color: LINE, border_width: 0.5, background_color: SHADE })
    pdf.move_down 14
  end

  def footer(pdf, generated)
    pdf.number_pages "#{safe(generated)}  ·  Page <page> of <total>", at: [pdf.bounds.left, -14],
                     width: pdf.bounds.width, align: :right, size: 7.5, color: MUTED
  end

  def money(cents) = Money.format(cents)

  def day(date) = date ? date.strftime("%-d %b %Y") : ""

  def safe(text) = text.to_s.encode("Windows-1252", invalid: :replace, undef: :replace, replace: "?").encode("UTF-8")
end
```

```ruby
module Finance
```

```ruby
  # finished row to open pages over Turbo Streams.
  class RenderReportJob < ApplicationJob
    queue_as :default

    def perform(export_id)
      export = ReportExport.find(export_id)
      taman = Taman.unscoped.find(export.taman_id)
      ActsAsTenant.with_tenant(taman) do
        Current.organization = taman.organization
        Current.taman_ids = [taman.id]
        bytes, filename = ExportReport.render(export)
        export.file.attach(io: StringIO.new(bytes), filename:, content_type: "application/pdf")
        export.update!(status: :ready)
      end
    rescue StandardError => e
      # ponytail: no retries — the page shows Failed and the user asks again.
      export&.update!(status: :failed, error: e.message.truncate(250))
      Rails.error.report(e)
    ensure
      if export
        Turbo::StreamsChannel.broadcast_replace_to([export.taman_id, :report_exports],
                                                   target: ActionView::RecordIdentifier.dom_id(export),
                                                   partial: "admin/ar_aging/export", locals: { export: })
      end
    end
  end
end
```
